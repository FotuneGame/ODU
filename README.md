# Численное интегрирование и решение ДУ

Практическая работа № 4. Вариант 3. K = 25, K mod 5 = 0.

## Запуск

Node.js 18.3 или новее.

```bash
npm install
npm start
```

## Расчёт

- Интеграл на `[0, π/2]` с шагами `π/10` и `π/50`. Методы центральных прямоугольников, трапеций и Симпсона по концам и середине каждого подынтервала. Точное значение `π sin(1) / 4`.
- Скалярное ДУ. Методы Эйлера, Эйлера с коррекцией по формуле трапеций, Рунге–Кутты третьего порядка и Адамса–Башфорта третьего и четвёртого порядков. Для РК3 используются стадии `0, h/2, h` с весами `1/6, 2/3, 1/6`.
- Система ДУ. Методы Эйлера, Эйлера с коррекцией, Адамса–Башфорта третьего порядка и Рунге–Кутты четвёртого порядка.
- Для скалярного ДУ начальное опорное значение `y(0) = 0,2` взято из варианта 3 и выводится в консоль. Конечную точку задаёт `scalar.end` в `input/data.json`. Для сравнения методов выбрано `scalar.end = 1`. Для системы используется отрезок `[0, 3]` из приложения 3. В обоих расчётах шаги равны `0,1` и `0,05`.
- Опорное решение вычисляется методом РК4 с последовательным делением шага пополам. Критерий остановки `max |Y(h/2) − Y(h)| / 15 ≤ 10⁻¹²` проверяется в общих узлах.

## Структура

```
input/data.json       исходные данные и параметры расчёта
src/methods/          квадратуры и методы решения ДУ
src/helpers/          функции варианта, сетка, опорное решение
src/solve.js          сравнение решений на двух сетках
src/generateChart.js  SVG-графики
src/index.js          расчёт и вывод результатов
output/               results.json и SVG-графики для обеих сеток
```

В `results.json` сохранены решения и ошибки в узлах, максимальные ошибки, число вычислений правой части и наблюдаемые порядки. Относительная ошибка записана в долях. Для системы при расчёте ошибок применяется норма `‖·‖∞`. Нулевые ошибки исключаются из логарифмических графиков.

Для каждого шага сохраняются три графика скалярного ДУ и два графика системы. К именам файлов для шага `h/2` добавлен суффикс `_fine`.
